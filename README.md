# Prakriti-AI

## AI-Powered Personalized Ayurveda Wellness Platform

### Project Description
Prakriti-AI is an AI-powered personalized Ayurveda wellness platform that analyzes a user's lifestyle, diet, sleep, activity, and wellness indicators to provide personalized recommendations.

## Problem Statement
Many people do not receive personalized Ayurveda wellness guidance. Traditional assessment methods are time-consuming and require expert consultation.

## Objectives
- Provide AI-based wellness assessment
- Generate personalized diet plans
- Recommend healthy lifestyle practices
- Support SDG 3 – Good Health and Well-being

## Stakeholders
- Users
- Wellness Practitioners
- Nutritionists
- Yoga Instructors
- Researchers
- Administrators

## Features
- AI Assessment
- Wellness Dashboard
- Diet Recommendation
- Sleep Monitoring
- Progress Tracking
- Reports

## Technology Stack
- HTML
- CSS
- Bootstrap
- JavaScript
- Chart.js

Mock dataset including wellness profiles, diet plans, lifestyle assessments, and wellness reports.
